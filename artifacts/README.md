# Artifacts

Put final call evidence here before submission.

- `transcripts/`: one `.txt` and/or `.jsonl` transcript per call
- `recordings/`: one `.ogg` or `.mp3` recording per call
- `bug-report.md`: final reviewed bug report

Use matching call ids across transcript and recording filenames, for example:

```text
transcripts/20260918T220000Z-01-schedule_new_patient.txt
recordings/20260918T220000Z-01-schedule_new_patient.mp3
```
